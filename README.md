# Review Splitter

A lightweight web-based academic tool for structuring reviewer comments and preparing clear point-by-point manuscript revision responses.

Live app:
https://tdirsehan.github.io/review-splitter/

## What it does

- Splits reviewer reports into structured items such as R1.1, R1.2, R2.1, and R2.2
- Helps organize a response for each individual reviewer comment
- Supports point-by-point academic response preparation
- Makes complex reviewer reports easier to manage during revision
- Designed as a simple browser-based workflow for authors and researchers

The application is published directly from the `main` branch using GitHub Pages.
